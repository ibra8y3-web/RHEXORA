# تقرير فشل البناء — RHEXORA

## مكان تنزيل التقرير
1. افتح المستودع على GitHub ثم **Actions**.
2. افتح تشغيل الـ Workflow الذي فشل.
3. انتظر انتهاء وظيفة **Collect complete build failure report**.
4. نزّل الـ Artifact الذي يبدأ اسمه بـ `rhexora-build-failure-`.
5. أرسل ملف ZIP هنا بعد مراجعة محتوياته.

## محتويات الحزمة
- `manifest.json`: بيانات التشغيل والـ Workflow والـ Jobs والملفات التي رصدتها السجلات.
- `logs/`: سجلات الوظائف الفاشلة التي أمكن تنزيلها من GitHub.
- `source/`: نسخ كاملة من الملفات التي ظهرت مساراتها في السجلات أو تغيرت في آخر commit.
- `README_AR.txt`: شرح مختصر للحزمة.

## تفسير الملفات
- `files_referenced_in_logs`: ملفات ظهرت مساراتها صراحةً في سجل الخطأ؛ هذا لا يثبت وحده أنها سبب المشكلة.
- `changed_files_in_commit`: ملفات تغيرت في آخر commit.
- `included_source_files`: الملفات التي أُرفقت نسخها الكاملة.

## الخصوصية
تُستبعد مجلدات وأسماء أسرار شائعة مثل `.env` و`secrets/` ومفاتيح SSH وملفات keystore. هذا الاستبعاد ليس ماسح أسرار كاملًا؛ راجع الحزمة يدويًا قبل مشاركتها، ولا ترفعها إلى مكان عام إذا تضمنت بيانات حساسة.
